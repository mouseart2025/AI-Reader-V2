## 关系维度判定（relationships 的三维字段）⚠️ 每条关系必填
除 relation_type 外，每条 relationship 必须额外输出三个独立维度字段：polarity、rel_subtype、closeness。三个维度各自独立判定，互不影响。

### 1. polarity（情感极性，三选一）
- `positive`：双方关系总体友善、亲密、互利。结拜、婚恋、同盟、报恩默认 positive；存在明确敌意描述时除外
- `negative`：双方关系敌对、仇恨、逼迫。敌对默认 negative；逼婚、情敌等逼迫/冲突关系归 negative
- `neutral`：事务性、无明确情感倾向，或文本未给出倾向。主从、君臣-上下级等制度性关系默认 neutral，除非文本明确写出亲疏好恶

### 2. rel_subtype（细化关系类型，13 选 1，不得输出表外的词）
| 取值 | 定义 | 例子 |
|---|---|---|
| `辈分-亲属` | 血缘或姻亲的辈分关系（含夫妻，夫妻为平辈姻亲） | 贾母与贾宝玉：祖孙 |
| `结拜` | 无血缘者依仪式结为拟制血亲（义结金兰、拜把子） | 宋江与武松结拜为义兄弟 |
| `婚恋` | 双向的恋爱/情人关系 | 贾宝玉与林黛玉相恋 |
| `爱慕` | 单方面的恋慕、暗恋、求亲，未获对方回应 | 贾瑞单恋王熙凤 |
| `师门-师徒` | 师父与弟子之间的垂直授受关系 | 唐僧与孙悟空：师徒 |
| `师门-同门` | 同一师门下的平辈关系（师兄弟、同门） | 孙悟空与猪八戒：师兄弟 |
| `主从` | 主人与仆从、雇佣与被雇佣的垂直关系 | 贾宝玉与袭人：主仆 |
| `君臣-上下级` | 政治/组织内的垂直统属关系 | 宋徽宗与高俅：君臣 |
| `同盟` | 为共同目标结成的对等联盟 | 梁山泊与二龙山联手抗官军 |
| `朋友-社交` | 平辈友人、同僚、邻里、世交等横向社交关系 | 鲁智深与林冲结为好友 |
| `恩怨-报恩` | 基于恩惠/救助的亏欠与报答关系 | 金翠莲父女感念鲁智深救命之恩 |
| `敌对` | 仇恨、对抗、加害与被害关系 | 林冲与高俅：迫害结仇 |
| `其他` | 以上 12 类均不覆盖的关系 | 观音灌溉人参果树一类叙事性关联 |

判定规则（按优先级）：
1. **先判文化特定关系**：结拜、师门（师徒/同门）、辈分-亲属优先判定，不得硬塞入"朋友-社交"或"其他"
2. **双向 vs 单向**：婚恋必须双向；单方面一律 `爱慕`，不得升级为 `婚恋`
3. **垂直 vs 水平**：师门内，师徒是垂直关系（`师门-师徒`），同门是水平关系（`师门-同门`）；同门不得并入师徒
4. **与 relation_type 的分工**：relation_type 仍是自由文本细类（父子、祖孙、嫂叔……），rel_subtype 是其上位维度槽位，二者不互相替代

### 3. closeness（亲疏程度，三选一）
- `close`：日常密切往来、利益/情感强绑定（共同行动、互相托付、频繁同场互动）
- `distant`：名义上有关系但少有实际往来（仅提及名分、远亲、多年未见）
- `unknown`：文本信息不足以判定亲疏（默认取值；无证据时不猜）

不确定时：polarity 取 `neutral`，closeness 取 `unknown`，rel_subtype 从 13 个取值中选最接近的一个，禁止输出取值表之外的词。
